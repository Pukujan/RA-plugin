# Aborted pilot attempts

These directories preserve raw OpenCode responses from attempts stopped when
the requested model pair changed. They are not included in the authoritative
pilot report and must not be used as benchmark evidence.

- `opencode-pilot/`: initial DeepSeek + Gemini Flash attempt, stopped on request.
- `opencode-pilot-lite/`: lighter-model attempt, stopped on request.
- `opencode-pilot-minimax-gemini/`: Minimax + Gemini attempt, stopped when Mimo was clarified.
